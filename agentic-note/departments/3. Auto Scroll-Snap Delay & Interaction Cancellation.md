## 2. Technical Implementation & Changes

### A. Auto Scroll-Snap & Interaction Handling in `js/departments.js`
The original logic executed a `setTimeout` of 1000ms (1 second) to auto-scroll into view without checking whether the user was already actively interacting with the page.

**Changes Implemented:**
1. **Interaction Detection**: Added global capture event listeners (`wheel`, `touchstart`, `touchmove`, `keydown`, `mousedown`, `pointerdown`) to intercept any direct user interaction on the page.
2. **Cancellation Logic**: If user interaction is detected before the timeout fires:
   - `autoScrollTimer` is cleared (`clearTimeout`).
   - Interaction listeners are removed from `window`.
   - `triggerFadeIn()` is invoked so `#semester-content-wrapper` still transitions to `opacity: 1` (`.semester-fade-in`), ensuring content visibility without forcing an annoying auto-scroll jump.
3. **Delayed Auto Scroll**: Set initial timeout delay to 5 seconds (`5000ms`).

```javascript
  // Scroll to semester content after 3 seconds (initially set to 5000ms) if department has semesters and user hasn't interacted
  if (semesters.length > 0) {
    let autoScrollTimer = null;
    let hasInteracted = false;

    const triggerFadeIn = () => {
      const wrapperEl = document.getElementById('semester-content-wrapper');
      if (wrapperEl) {
        wrapperEl.classList.add('semester-fade-in');
      }
    };

    const handleUserInteraction = () => {
      if (hasInteracted) return;
      hasInteracted = true;

      if (autoScrollTimer) {
        clearTimeout(autoScrollTimer);
        autoScrollTimer = null;
      }

      removeInteractionListeners();
      // Ensure content is visible if user interacts before auto-scroll
      triggerFadeIn();
    };

    const interactionEvents = ['wheel', 'touchstart', 'touchmove', 'keydown', 'mousedown', 'pointerdown'];

    const removeInteractionListeners = () => {
      interactionEvents.forEach(event => {
        window.removeEventListener(event, handleUserInteraction, { capture: true });
      });
    };

    interactionEvents.forEach(event => {
      window.addEventListener(event, handleUserInteraction, { capture: true, passive: true });
    });

    autoScrollTimer = setTimeout(() => {
      removeInteractionListeners();
      if (!hasInteracted) {
        const contentEl = document.getElementById('semester-content');
        if (contentEl) {
          contentEl.scrollIntoView({ behavior: 'smooth' });
        }
        triggerFadeIn();
      }
    }, 3000);
  }
```
