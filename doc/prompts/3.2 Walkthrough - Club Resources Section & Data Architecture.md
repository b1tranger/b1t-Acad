## 2. Frontend UI & Modal Implementation (`index.html`, `style.css`)

### A. Sub-section in `#ECA`: Club Resources
- Added the **Club Resources** container directly inside `#ECA`.
- Integrated an icon heading and explanatory subtitle.
- Rendered interactive club button cards via `#club-buttons-list` matching `.resource-link` pill aesthetics.
- **Single-Column Mobile Screen Optimization (`max-width: 600px`)**:
  - Automatically switches `#club-buttons-list` to a centered vertical flex column layout.
  - Buttons (`.club-btn-trigger`) expand to `width: 90% !important`, replacing the fixed `160px` desktop pill width.
  - Eliminates excessive empty side margins and ensures long club titles wrap cleanly without crowding.

### B. Sub-section in `#ECA`: Interests & Skills Development Table with 2nd-Line Mobile Tooltips
- Responsive 3-column table:
  - **Resource**: Name with distinctive FontAwesome icon.
  - **Scope / Description**: Contextual description for each track (`.col-scope-desc`).
  - **Link / Action**: Themed buttons (`Open Folder`, `Website`, `Visit Site`, `Read Blog`, `Tutorials`).
- **Mobile Screen Optimization (`max-width: 680px`)**:
  - Hides the "Scope / Description" column (`.col-scope-desc`) to eliminate horizontal squishing on small viewports.
  - Moves info tooltips to a dedicated second line beneath each resource name (`.row-desc-tooltip-wrap`) with `margin-left: 24px` to align perfectly under the resource title.
  - Styled as an interactive pill button (`[ ⓘ Info ]`) with accent border and subtle background tint.
  - Tooltip bubbles feature glassmorphism dark/gray theme adaptive cards with arrow pointers, smooth fade/scale transitions, and upward orientation (`.tooltip-up`) for lower rows to avoid viewport clipping.
  - Supported via `:hover`, `:focus`, `:focus-within`, and a tap-toggle click listener in [`js/club-resources.js`](file:///d:/GitHub/[oU1TS]/b1t-Acad/js/club-resources.js) that dismisses on outside clicks.

### C. Interactive Wings Modal with Truly Circular Protruding Close Button (`#club-wings-modal`)
- Modal overlay with dark backdrop blur and `20px` edge padding.
- **Circular Protruding Close Button**:
  - Positioned at `top: -14px; right: -14px;` (`-10px` on small screens <= 480px), floating outside the top-right corner of the modal container.
  - Purged `.btn` and `.btn-icon` classes to prevent unwanted `15px 30px` padding and `8px` border-radius overrides.
  - Formatted strictly with `36px` dimensions, `border-radius: 50% !important;`, `padding: 0 !important;`, `margin: 0 !important;`, and centered flex alignment to guarantee a perfect circle on all screen sizes.
- Header displaying the department club name, department title, and icon with rounded top corners (`12px`).
- Meta info box with club overview and direct link to the main Club Google Drive folder (`club_res`).
- Responsive card list displaying subsidiary focus wings with direct Google Drive links.

### D. Homepage oU1TS Portal Highlighted Action Button (`index.html`, `style.css`)
- Replaced the homepage "Need help with studies?" button and the static text paragraph at the bottom of the main hero section with a dedicated, floating highlighted action button (`.ou1ts-portal-btn`).
- Text content: `Visit oU1TS Portal for more projects! &nbsp;<i class="fa-solid fa-arrow-up-right-from-square"></i>`
- Links to `https://ouits-res.netlify.app/` with `target="_blank"` and `rel="noopener noreferrer"`.
- **Wider Display Fix**: Resolved a missing closing brace on `@media (max-width: 480px)` in [`index.html`](file:///d:/GitHub/[oU1TS]/b1t-Acad/index.html) that previously restricted the button styles to mobile viewports only, and added global styles in [`style.css`](file:///d:/GitHub/[oU1TS]/b1t-Acad/style.css) ensuring optimal rendering on desktop, tablet, and mobile.

### E. Scrollbar Layout Stability & Custom Matte Scrollbars
- **Layout Stability on Sidebar Expansion**:
  - Added `html { scrollbar-gutter: stable; overflow-y: scroll; }` to permanently preserve the scrollbar track gutter, preventing the page from shifting or changing width when the mobile sidebar drawer or modal toggles `body.no-scroll`.
  - Added `overflow-y: auto; overscroll-behavior: contain;` to `.sticky-nav` on mobile to ensure smooth drawer scrolling without interfering with background viewport bounds.
- **Universal Custom Matte Scrollbars**:
  - Standardized cross-browser matte scrollbar palette via standard `scrollbar-width: thin` / `scrollbar-color` and WebKit pseudo-elements (`::-webkit-scrollbar`).
  - Dark theme: Matte deep slate/charcoal track (`#14151e`) and muted graphite thumb (`#343948`), transitioning to `#4a5166` on hover.
  - Gray theme: Soft light-gray track (`#ebeef2`) with slate thumb (`#aeb4c0`).
  - Applied globally to `*`, modals, sidebar, code viewers, and lists.
