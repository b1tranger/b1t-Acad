# Implementation Plan: QBank Full-Screen Modal, Mobile Home Button & Light Theme Contrast Audit

We will implement three core enhancements to polish the website:
1. Convert the QBank dropdown browser into an expansive full-screen popup modal with a protruding circular close button and tap-outside-to-close functionality.
2. Reposition the mobile "Home" (SPA Back) button to the bottom-right corner and fix the dark theme hover font color to pure white.
3. Conduct a comprehensive light theme (`[data-theme="gray"]`) contrast audit across all pages, extracting rules from the desktop-only media query and overriding hardcoded white text, icons, tooltips, and cards.

---

## User Review Required

> [!NOTE]
> - The QBank trigger button in `#Qbank` ("📁 Browse Question Bank") will now open the full-screen modal rather than expanding an inline accordion.
> - Mobile `#spa-back-btn` will be anchored at `bottom: 2rem; right: 1.5rem;` instead of centered `left: 50%`.

### Component 3: Light Theme Contrast Audit & Fixes (`style.css`, `index.html`)

#### [MODIFY] [`style.css`](file:///d:/GitHub/[oU1TS]/b1t-Acad/style.css)
- **Un-nest Global Light Theme Rules**: Move `[data-theme="gray"]` styles for `.upload-section`, `.content-section p`, `.info-nav-link`, `.resource-link`, and `.grid-button` out of `@media (min-width: 769px)` so they apply seamlessly to both desktop AND mobile screens.
- **High-Contrast Text Overrides for Light Mode**:
  - Add explicit overrides for hardcoded inline white styles:
    - `.content-section a[style*="color: white"]`, `a[style*="color:white"]`, `a[style*="whitesmoke"]` $\rightarrow$ `color: var(--accent-color) !important;`
    - `.content-section p[style*="color: rgba(255, 255, 255"]` $\rightarrow$ `color: #444444 !important;`
  - Ensure `.qbank-toggle` and `#open-qbank-modal-btn` have dark borders `#333` and text `#1a1a1a`.
  - Ensure file explorer items (`.explorer-item`, `.explorer-item-name`, `.explorer-breadcrumbs`, `.explorer-crumb`) maintain high contrast in light mode (`color: #1a1a1a; background: #e5e5e5;`).
  - Ensure tooltip bubble (`.row-desc-tooltip-bubble`) in light mode uses `background: #f0f0f0; color: #1a1a1a; border-color: #bfbfbf;`.
  - Ensure table borders and table text in ECA section have crisp contrast in light mode.
