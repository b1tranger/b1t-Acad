# Implementation Plan - Submission Page Mobile Enhancements & Notice Minimization

This plan outlines the enhancements for [`submission.html`](file:///d:/GitHub/%5BoU1TS%5D/b1t-Acad/submission.html) focusing on responsive mobile interactions, dynamic UI animations, and clean iconography.

## User Review Required

> [!IMPORTANT]
> 1. **Auto-Minimization Timing**: The notice block (`.page-description`) will be prominently displayed on page load, then automatically smoothly fly up and minimize into a top bar information icon after **4 seconds**. Hovering over the banner will temporarily pause the timer.
> 2. **Mobile Floating Back Button**: On screens $\le 768\text{px}$, the back button will float at the bottom-right corner (`bottom: 2rem; right: 1.5rem;`) mirroring the home button styling on `index.html`.
> 3. **Icon-Only Action Buttons**: On screens $\le 768\text{px}$, the text for the notification actions (Enable Notifications, Recent Submissions, Make Submission) will be hidden, transforming them into sleek $44\times 44\text{px}$ circular icon buttons with tooltips.

---

## Proposed Changes

### `submission.html`

#### 1. Mobile Floating Back Button
- In `@media (max-width: 768px)`:
  - Reposition `.back-btn` to `position: fixed; bottom: 2rem; right: 1.5rem; z-index: 999;`.
  - Apply pill shape (`border-radius: 50px`), dark translucent glass background (`rgba(26, 26, 46, 0.95)`), backdrop blur, and neon border glow.
  - Fix hover state to ensure high contrast and white text.
  - Remove from header flex flow on mobile so `.category-header` layout remains balanced.

#### 2. Notice Block Minimization & Top Bar Info Icon
- **Top Bar Trigger**:
  - Add `<button id="notice-info-trigger" class="notice-info-trigger" title="Page Information" aria-label="Toggle page information notice">` inside `.category-header`.
  - Position it at the top-right corner of the header card.
- **Collapsible Overlay Banner**:
  - Assign ID `#page-notice-banner` to `.page-description`.
  - Add a dismiss button `<button id="notice-close-btn" class="notice-close-btn">` within the banner.
  - Add CSS transitions for `max-height`, `opacity`, `transform`, `margin`, `padding`.
  - In expanded state: displays as an elegant card with subtle backdrop glow.
  - In minimized state: collapses seamlessly (`transform: translateY(-20px) scale(0.85); opacity: 0; max-height: 0; pointer-events: none;`).
- **Dynamic JavaScript Logic**:
  - Set a 4-second timer on page load to automatically trigger minimization.
  - Trigger a pulse highlight on the top bar info icon when minimization completes to indicate its new home.
  - Clicking the `#notice-info-trigger` icon smoothly toggles the notice banner between expanded and minimized states.
  - Hovering over the banner pauses auto-minimization.

#### 3. Mobile Icon-Only Action Buttons
- Wrap the raw text `Make Submission` in `<span class="submit-btn-text">Make Submission</span>`.
- In `@media (max-width: 768px)`:
  - Hide `#notif-btn-text`, `#recent-bell-text`, and `.submit-btn-text` (`display: none !important;`).
  - Convert `.notif-enable-btn`, `.recent-bell-btn`, and `.submit-resource-btn` into $44\times 44\text{px}$ circular touch buttons with centered icons.
  - Retain `title` and `aria-label` for full accessibility.

### Manual Verification
- **Mobile Viewport ($\le 768\text{px}$)**:
  - Verify back button floats at bottom-right and navigates correctly to `index.html`.
  - Verify the 3 action buttons render as compact circular icon buttons without text overflow.
- **Notice Animation**:
  - Verify banner appears immediately on page load.
  - Verify banner automatically minimizes into the top-bar info icon after 4 seconds.
  - Verify clicking the top-bar info icon re-expands the banner with smooth slide/fade animation.
  - Verify clicking the icon again or clicking the close button collapses it back.
