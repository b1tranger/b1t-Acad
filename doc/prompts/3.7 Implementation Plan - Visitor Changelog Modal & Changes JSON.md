# Implementation Plan - Visitor Changelog Modal & Changes JSON

Create an automated visitor changelog popup modal for [`b1t-Acad`](file:///d:/GitHub/%5BoU1TS%5D/b1t-Acad/index.html) that notifies visitors whenever a new website update is deployed, indicated by `CACHE_NAME` in [`sw.js#L2`](file:///d:/GitHub/%5BoU1TS%5D/b1t-Acad/sw.js#L2). The feature is modeled directly on the design and architecture of [`b1t-Sched`](file:///d:/GitHub/%5BoU1TS%5D/b1t-Sched/) (`changes.json`, `changelog-modal.js`, and `changelog.css`), populated with historical releases from [`doc/history.md`](file:///d:/GitHub/%5BoU1TS%5D/b1t-Acad/doc/history.md).

## User Review Required

> [!IMPORTANT]
> 1. **Version Synchronization**: The version tracked in `changes.json` (`currentVersion`) will align directly with `const CACHE_NAME` in `sw.js`. We will set this to `'v6.9'` (with full history backwards to `v5.0`) so that on next deployment, all visitors will receive the new modal.
> 2. **Persistence**: The modal records the dismissed version in `localStorage.setItem('b1t_acad_last_seen_version', currentVersion)`. It only pops up automatically when a newer version is deployed, or when manually triggered by clicking "What's New" in the footer.
> 3. **Theming**: The modal includes comprehensive dark and light theme (`[data-theme="gray"]`) styling, protruding circular close button, and vivid tag pills.

### Logic & Scripts

#### [NEW] [`js/changelog-modal.js`](file:///d:/GitHub/%5BoU1TS%5D/b1t-Acad/js/changelog-modal.js)
- Implement `ChangelogModal` module:
  - `fetchChanges()`: Fetches `/changes.json?t=<timestamp>` to bypass HTTP caching.
  - `checkAndShowChangelog(forceOpen)`: Compares `localStorage.getItem('b1t_acad_last_seen_version')` against `data.currentVersion`. Opens modal automatically on mismatch.
  - `render(data)`: Populates modal title, version badge, latest changes list, and collapsible accordion (`#changelog-history-toggle`) for earlier releases.
  - `setupEventListeners()`: Handles dismiss triggers (close button, "Got it" button, click-outside backdrop, and `Escape` key), storing the seen version in `localStorage`.
  - Manual trigger hook for `#view-changelog-link`.
  - Auto-initializes on DOM ready.

## Verification Plan

- Validate JSON syntax of `changes.json`:
  ```bash
  node -e "JSON.parse(fs.readFileSync('changes.json', 'utf8')); console.log('changes.json OK')"
  ```
- Validate JavaScript syntax of `js/changelog-modal.js` and `sw.js`:
  ```bash
  node -c js/changelog-modal.js; node -c sw.js
  ```

### Manual Verification
- **First Visit / Update Detection**:
  - Clear `localStorage.removeItem('b1t_acad_last_seen_version')`.
  - Reload `index.html` -> Verify `#changelog-modal` automatically opens showing version `v6.9` and latest changes.
  - Click "Got it" -> Verify modal closes and `b1t_acad_last_seen_version` is stored.
  - Reload page -> Verify modal does NOT pop up again.
- **Manual Trigger**:
  - Click "What's New" link in footer -> Verify modal opens on demand.
- **Earlier Releases Accordion**:
  - Click "View Earlier Updates" -> Verify accordion smoothly expands displaying previous versions (`v6.8`, `v6.7`, `v6.6`, `v5.5`, `v5.0`).
- **Dismiss Interactions**:
  - Verify close button, backdrop click, and `Escape` key all close the modal.
- **Theme & Responsiveness**:
  - Toggle between dark theme and light theme (`[data-theme="gray"]`) to verify color contrast.
  - Test on mobile width ($\le 768\text{px}$) to verify edge-to-edge modal padding and button hitboxes.
