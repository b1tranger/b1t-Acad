# Walkthrough - Visitor Changelog Modal & Changes JSON Architecture

We implemented an automated "What's New" visitor changelog modal for [`b1t-Acad`](file:///d:/GitHub/%5BoU1TS%5D/b1t-Acad/index.html) modeled on [`b1t-Sched`](file:///d:/GitHub/%5BoU1TS%5D/b1t-Sched/), automatically detecting new releases via `CACHE_NAME` in [`sw.js`](file:///d:/GitHub/%5BoU1TS%5D/b1t-Acad/sw.js), with structured data populated from [`doc/history.md`](file:///d:/GitHub/%5BoU1TS%5D/b1t-Acad/doc/history.md).

## Changes Made

### 1. Data Layer: Structured `changes.json`
- Created [`changes.json`](file:///d:/GitHub/%5BoU1TS%5D/b1t-Acad/changes.json) following `b1t-Sched`'s schema:
  - Tracks `currentVersion` (`"v6.9"`), `lastUpdated` (`"September 2026"`), and `documentationUrl` (`"doc/history.md"`).
  - Populated complete release history from [`doc/history.md`](file:///d:/GitHub/%5BoU1TS%5D/b1t-Acad/doc/history.md):
    - `v6.9`: Visitor Changelog Modal & Changes JSON Architecture + Course Search Enter Selection.
    - `v6.8`: Dark Theme Contrast for Mirror Links & Sitewide `.link-hover-a`.
    - `v6.7`: Submission Page Mobile Floating Back Button, Collapsible Notice Banner & Icon Action Buttons.
    - `v6.6`: Club Resources Sub-Section & Wings Modal, QBank Modal, Mobile Home Button, 100vh Viewport Scroll Optimization, Universal Matte Scrollbars, Light Theme Contrast Audit.
    - `v5.5`: Visitor Counter & Glitch Intro Archival to `old-code/`.
    - `v5.0`: Legacy Codebase & Old Design Architectural Archive + Agent Guidelines.

### 2. Client Controller: `js/changelog-modal.js`
- Created [`js/changelog-modal.js`](file:///d:/GitHub/%5BoU1TS%5D/b1t-Acad/js/changelog-modal.js):
  - Fetches `/changes.json?t=<timestamp>` to bypass HTTP caching.
  - Compares `localStorage.getItem('b1t_acad_last_seen_version')` against `data.currentVersion`.
  - Automatically pops up the modal if the user has not seen the active version.
  - Dynamically renders latest release cards, category tag badges (`new-feature`, `fix`, `enhancement`, `ui-ux`, `major`, `security`, `refactor`, `docs`), and an expandable accordion (`#changelog-history-toggle`) for older versions.
  - Dismissing via "Got it" button, protruding close button (`x`), backdrop tap, or `Escape` key saves the seen version to `localStorage` and closes the modal.
  - Supports manual re-opening via `#view-changelog-link`.

### 3. Modal Styles: `style.css`
- Added comprehensive changelog styling in [`style.css`](file:///d:/GitHub/%5BoU1TS%5D/b1t-Acad/style.css):
  - Backdrop overlay with blur (`.changelog-modal-overlay`).
  - Dark glassmorphic dialog (`#161b22`) with neon blue accent border and scale/fade-in animation.
  - Protruding circular top-right close button (`#close-changelog-modal`) with hover rotation and glow.
  - Vivid category tag badges with translucent backgrounds.
  - Custom matte scrollbar matching the site's design language.
  - Accordion for earlier releases with rotating chevron.
  - Comprehensive light gray theme overrides under `[data-theme="gray"]`.
  - Mobile responsive rules for $\le 768\text{px}$ and $\le 480\text{px}$.

### 4. Markup Integration: `index.html`
- In [`index.html`](file:///d:/GitHub/%5BoU1TS%5D/b1t-Acad/index.html):
  - Added `#changelog-modal` markup before `</body>`.
  - Included `<script src="js/changelog-modal.js"></script>`.
  - Added a "What's New" link (`#view-changelog-link`) in the footer mirror banner next to Netlify and GitHub.

### 6. Modal DOM Hierarchy, Drawer Layout & Resiliency Fixes (`v7.0` - `v7.6`)
- **Support Button & Mobile Drawer Overlap Prevention (`v7.6`)**: Lowered `#support-qr-persistent` ("Coffee?" button) `z-index` to `2500` in [`index.html`](file:///d:/GitHub/[oU1TS]/b1t-Acad/index.html) and elevated mobile `.sticky-nav` (`3500`), `.overlay` (`3400`), and `.menu-toggle` (`3501`) in [`style.css`](file:///d:/GitHub/[oU1TS]/b1t-Acad/style.css). Added automatic fade-out and pointer-events deactivation for `#support-qr-persistent` whenever the mobile drawer is open.
- **Mobile Drawer Centering & Overlap Margin (`v7.5`)**: Added `margin-top: 8.5rem;` and `min-height: calc(100% - 8.5rem);` to `.sticky-nav ul` in [`style.css`](file:///d:/GitHub/[oU1TS]/b1t-Acad/style.css) within the mobile media query. Completely eliminated overlap with `#floating-button-nav` ("b1t Scheduler") and centered the menu links vertically within the drawer.
- **Unclosed Parent Tag Fix (`v7.4`)**: Discovered an unclosed `<div id="qbank-modal">` prior to `#changelog-modal` in [`index.html`](file:///d:/GitHub/[oU1TS]/b1t-Acad/index.html). Because `#qbank-modal` carried `style="display: none;"`, `#changelog-modal` was trapped inside a hidden parent tree. Inserted the closing `</div>` to make `#changelog-modal` a direct child of `<body>`. Tag balance audit confirmed 0 unclosed div tags sitewide.
- **Mobile Drawer Changelog Button (`v7.3`)**: Relocated the changelog trigger to the very bottom of the mobile navigation drawer (`#sticky-nav ul`) with `margin-top: auto;` and a separator border.
- **Offline & `file:///` Resiliency (`v7.2`)**: Embedded `CHANGELOG_DATA_FALLBACK` directly into [`js/changelog-modal.js`](file:///d:/GitHub/[oU1TS]/b1t-Acad/js/changelog-modal.js) so the modal always loads even when CORS blocks `fetch('changes.json')` under `file://`.
- **Manual Trigger Buttons (`v7.1`)**: Added bottom-left glassmorphic button for desktop and mobile drawer navigation item with live version badge pill.
- **Course Search Clear Button (`v7.0`)**: Added circular clear button inside search bar with dual-theme styling.
