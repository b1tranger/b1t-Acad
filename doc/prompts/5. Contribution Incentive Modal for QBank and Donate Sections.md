## Turn 3: Donate Section FAQ Tooltip Grace Period & Hover Bridge

### User Request
```text
@[d:\GitHub\[oU1TS]\b1t-Acad\index.html:L1781-L1799] make the tooltip stay longer after cursor is unhovered. Since it hides immediately.
```

### Thinking
- Analyzed the issue with the reconstructed questions FAQ tooltip (`.faq-tooltip-container` / `.faq-tooltip-content`) inside the Donate section:
  1. The tooltip hid immediately upon moving the cursor off the icon because there was no transition delay on the unhover state (`.faq-tooltip-content`).
  2. The tooltip is positioned at `top: 140%`, leaving a dead zone gap between the icon and the tooltip body, causing premature hover dropouts when users attempted to move towards the tooltip body and clickable links inside (`Question` and `txt` example links).
  3. Mobile touch devices could not reliably pin or interact with the tooltip.
- Implemented solution:
  1. In `index.html` inline `<style>`:
     - Added a 1-second grace period transition delay on unhover: `transition: opacity 0.35s ease 1s, transform 0.35s cubic-bezier(0.175, 0.885, 0.32, 1.275) 1s, visibility 0.35s ease 1s;`.
     - Added instant-open transition delay reset (`0s`) on hover: `.faq-tooltip-container:hover .faq-tooltip-content`, `.faq-tooltip-container.active .faq-tooltip-content`, `.faq-tooltip-content:hover`.
     - Created an invisible bridge pseudo-element (`.faq-tooltip-content::before`) spanning `bottom: 100%; height: 35px;` so the mouse cursor never loses hover when traveling between the icon and the tooltip body.
     - Applied identical grace periods and hover bridge rules to the mobile media query (`@media (max-width: 768px)`).
  2. In `index.html` click handler:
     - Added tap-to-toggle click listener on `.faq-tooltip-container` / `.faq-icon` with tap-outside dismissal, enabling mobile visitors to pin the tooltip open and read comfortably.
  3. Repository synchronization per guidelines:
     - Bumped Service Worker `CACHE_NAME` to `'v9.0'` in `sw.js`.
     - Synchronized `changes.json` and `js/changelog-modal.js` fallback data to `v9.0`.
     - Updated version badges in `index.html` to `v9.0`.
     - Added release notes under `# 19.09.26` in `doc/history.md`.
     - Validated JS and JSON syntax.
     - Appended Turn 3 to session prompt archive and generated Git commit recommendation.
