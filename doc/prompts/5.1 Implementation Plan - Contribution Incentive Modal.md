# 5.1 Implementation Plan - First-Visit Contribution Incentive Modal for QBank & Donate

Add a responsive introductory modal that prompts first-time visitors of the **Question Bank (`#Qbank`)** and **Donate Resources (`#Donate`)** sections with a motivational call-to-action explaining the community-driven "donation" cycle and urging contributions of exam questions and notes.

## User Review Required

> [!NOTE]
> - **Display Frequency**: The modal will appear automatically **once** upon the user's first visit to either the `#Qbank` or `#Donate` section, tracked in `localStorage` (`b1t_contribution_intro_seen`).
> - **Re-open Access**: In addition to the first-visit auto-popup, a subtle re-open trigger (e.g. `💡 Why donate? / কেন donate করবেন?`) will be provided in both sections so visitors can easily re-read the message at any time.
> - **Dual-Theme Support**: The modal will support both Dark theme and Light/Gray mode (`[data-theme="gray"]`).

## Proposed Changes

Grouped by component:

---

### UI & Modal Structure

#### [MODIFY] [`index.html`](file:///d:/GitHub/%5BoU1TS%5D/b1t-Acad/index.html)
- Insert the modal HTML `#contribution-modal` before the closing `</body>` tag (adjacent to `#changelog-modal`).
- Include:
  - Protruding circular close button (`#close-contribution-modal`).
  - Header banner with motivational icon (`fa-hand-holding-heart`), English title, and bilingual subtitle.
  - Callout card with the English message:
    > *"Attention!! If you were ever benefited from this Project, please consider contributing by donating Questions/Notes or spreading the word! Appreciated 👍"*
  - Bengali body section rendering the full verbatim message with clean paragraph structure and emphasis on key concepts ("donation", "system", "দায়িত্ব আপনার, আমার, আমাদের").
  - Closing card with the benediction:
    > *"JazakAllahu Khairan. BarakAllahu Feekum."*
  - Modal footer with a primary dismiss button (*"Got it / বুঝেছি 👍"*) and a quick action link (*"Contribute Now"*).
- Add subtle manual trigger badges/buttons in `#Qbank` and `#Donate` allowing users to re-open the modal whenever desired.
- Include script tag `<script src="js/contribution-modal.js"></script>`.

### Logic & Routing Integration

- Trigger detection:

  - On `hashchange`: check if new hash is `#Qbank` or `#Donate`.

  - Manual triggers: open modal without setting `localStorage` flag to false.
- Dismiss handlers: close on (X) button, "Got it" button, clicking outside overlay, and pressing `Escape`.
