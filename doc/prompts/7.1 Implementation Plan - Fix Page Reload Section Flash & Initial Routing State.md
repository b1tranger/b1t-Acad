# 7.1 Implementation Plan - Fix Page Reload Section Flash & Initial Routing State

Eliminate the brief flash of the desktop sticky navigation header (`.content-section-nav sticky-nav visible`) and other content sections during homescreen page reload (`#intro`), ensuring that on page reload the initial routing state is checked immediately, and non-home sections remain hidden unless accessed via redirect links.

## User Review Required

> [!NOTE]
> - **Immediate State Check**: An ultra-lightweight inline script executes in `<head>` before any body elements are parsed, checking `window.location.hash` and setting either `page-state-home` or `page-state-section` on `<html>`.
> - **Zero-FOUC Guarantee**: `.content-wrapper` is hidden by default in both CSS and HTML inline styles, preventing the browser engine from rendering `.content-section` or `.content-section-nav sticky-nav visible` before JS runs.
> - **Direct Hash Reload Support**: If a visitor reloads directly on a section hash (e.g. `#Qbank`, `#Departments`), `page-state-section` immediately displays `.content-wrapper` and `:target` while suppressing `#intro`, preventing homescreen flashing on direct section visits.
> - **Cache Bump**: Service worker cache bumped to `v9.8` with `changes.json` and visitor changelog synchronized.

## Proposed Changes

### 1. HTML Markup & Early State Detection

#### [MODIFY] [`index.html`](file:///d:/GitHub/%5BoU1TS%5D/b1t-Acad/index.html)
- Add an early inline script in `<head>` (right after `style.css`) that inspects `window.location.hash` immediately:
  - Valid section hashes: `#info`, `#Qbank`, `#Departments`, `#Donate`, `#ECA`, `#Library`, `#About`, `#book-session`.
  - If a valid section hash is present, add `page-state-section` to `document.documentElement`.
  - Otherwise (empty hash, `#`, `#course-search`, or invalid hash), add `page-state-home` to `document.documentElement`.
- Add inline `style="display: none;"` to `<div class="content-wrapper">` (line 1548) so the browser parser never renders content sections or the top navigation bar during initial homescreen parse.
- Bump changelog badges from `v9.6` to `v9.8` (`#desktop-changelog-btn`, `#mobile-changelog-btn`, `#changelog-version-badge`).

---

### 2. Styling & Layout Control

#### [MODIFY] [`style.css`](file:///d:/GitHub/%5BoU1TS%5D/b1t-Acad/style.css)
- Set default `display: none;` on `.content-wrapper` and `.content-section`.
- Add state-based selectors:
  - `html.page-state-home .content-wrapper { display: none !important; }`
  - `html.page-state-section #intro { display: none !important; }`
  - `html.page-state-section .content-wrapper { display: block !important; }`
  - `html.page-state-section .content-section:target { display: block !important; }`
  - `html.page-state-section #info:has(#book-session) { display: block !important; }`
  - `html.page-state-section #spa-back-btn { display: flex !important; }`

### 3. SPA Routing Controller Synchronization

#### [MODIFY] [`js/spa.js`](file:///d:/GitHub/%5BoU1TS%5D/b1t-Acad/js/spa.js)
- Add `updatePageState(isSection)` helper to dynamically toggle `page-state-home` and `page-state-section` on `document.documentElement`.

- Add case-insensitive section matching so hash fragments like `#qbank` or `#departments` resolve reliably.
