# Implementation Plan - Archived Courses Section & Semester Data Structure

Introduce an `archivedCourses` array variable for each semester in [`js/departments-data.js`](file:///d:/GitHub/%5BoU1TS%5D/b1t-Acad/js/departments-data.js), and dynamically render an **"Archived Courses"** section immediately below the Course Materials section in [`js/departments.js`](file:///d:/GitHub/%5BoU1TS%5D/b1t-Acad/js/departments.js).

---

## User Review Required

> [!NOTE]
> - `archivedCourses` will be added to every semester object (`S01` through `S08`) across all departments in [`js/departments-data.js`](file:///d:/GitHub/%5BoU1TS%5D/b1t-Acad/js/departments-data.js).
> - In [`js/departments.js`](file:///d:/GitHub/%5BoU1TS%5D/b1t-Acad/js/departments.js), an "Archived Courses" section (`<section id="archived-courses" class="content-section">`) will be generated below `<section id="courses">`.
> - If `archivedCourses` is defined and contains courses (`archivedCourses.length > 0`), it renders the cards identically styled using `.course-card-container` and `.course-button` / `.others-btn`.
> - If `archivedCourses` is empty or omitted for a semester, the section will gracefully remain hidden or render a clean fallback message.
