# Walkthrough - Archived Courses Data Architecture & Dedicated UI Section

Implemented the `archivedCourses` array variable across all semester objects in [`js/departments-data.js`](file:///d:/GitHub/%5BoU1TS%5D/b1t-Acad/js/departments-data.js) and introduced a dedicated dynamic **"Archived Courses"** section in [`js/departments.js`](file:///d:/GitHub/%5BoU1TS%5D/b1t-Acad/js/departments.js) situated immediately below the Course Materials section.

---

## Changes Implemented

### 1. Semester Data Model (`js/departments-data.js`)
- Added `"archivedCourses": []` to each semester (`S01` through `S08`) across all defined departments (`CSE`, `CE`, and `IT`).
- Migrated legacy courses (the previously commented `"Software Eng."` and `"I&OM"` in CSE Semester 06) directly into the `archivedCourses` list with active Google Drive links and FontAwesome icons (`fa-cogs`, `fa-briefcase`).

### 2. Dedicated UI Section (`js/departments.js`)
- Updated `loadSemester()` to inspect `semData.archivedCourses`.
- If `semData.archivedCourses` contains courses:
  - Dynamically renders `<section id="archived-courses" class="content-section" style="min-height: auto; margin-top: 2rem;">`.
  - Appends `<h2 style="text-align: center; margin-bottom: 30px;">Archived Courses</h2>`.
  - Renders cards within `<div class="course-card-container">` supporting standard `.course-button` cards and full-width `.others-btn` cards.
  - Adds contextual helper text: *"Archived courses from previous syllabus versions or curriculums"*.
- If `archivedCourses` is empty or undefined, the section cleanly does not render, preserving standard spacing.
