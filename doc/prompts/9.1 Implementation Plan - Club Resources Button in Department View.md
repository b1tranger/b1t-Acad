# Implementation Plan: Club Resources Button in Department View

Add a dedicated **Club Resources** button to [Departments.html](file:///d:/GitHub/[oU1TS]/b1t-Acad/Departments.html) driven by the `club_res` property in [js/departments-data.js](file:///d:/GitHub/[oU1TS]/b1t-Acad/js/departments-data.js) (corresponding to the departmental student clubs architecture in [js/clubs-data.js](file:///d:/GitHub/[oU1TS]/b1t-Acad/js/clubs-data.js) and [js/club-resources.js](file:///d:/GitHub/[oU1TS]/b1t-Acad/js/club-resources.js)). In [js/departments.js](file:///d:/GitHub/[oU1TS]/b1t-Acad/js/departments.js), configure the button setup alongside the existing Departmental Info and Question Bank buttons, and style it to show center-aligned on mobile screen widths.

---

## 1. Problem Overview
- [js/departments-data.js](file:///d:/GitHub/[oU1TS]/b1t-Acad/js/departments-data.js) defines a `club_res` variable for each department (e.g. `CSE.club_res` pointing to the main club Google Drive folder), which pairs with [js/clubs-data.js](file:///d:/GitHub/[oU1TS]/b1t-Acad/js/clubs-data.js) and [js/club-resources.js](file:///d:/GitHub/[oU1TS]/b1t-Acad/js/club-resources.js).
- In [Departments.html](file:///d:/GitHub/[oU1TS]/b1t-Acad/Departments.html), only buttons for `info_link` (`#dept-info-wrapper`) and `qbank_link` (`#qbank-info-wrapper`) are currently rendered in `.dept-buttons-row`.
- No button currently surfaces `club_res`, meaning visitors browsing department pages cannot access departmental club resources directly from the header controls.
- On mobile screen widths, three buttons side-by-side become cramped; the new button needs to wrap cleanly and be horizontally **center-aligned** on its own row below the top two buttons.

---

## 2. Proposed Changes

### A. Markup & CSS in [Departments.html](file:///d:/GitHub/[oU1TS]/b1t-Acad/Departments.html)
1. **Button Container Markup**:
   - Add `<div id="club-info-wrapper" class="info-btn-wrapper club-btn-wrapper" style="display: none;"></div>` directly within `.dept-buttons-row`, beside `#dept-info-wrapper` and `#qbank-info-wrapper`.
2. **Styling & Color Scheme**:
   - Add `.club-btn` styled in Chakra UI Green 500 (`background: #38a169;`) and Green 600 hover (`background: #2f855a;`), harmonizing with `.info-btn` (`#3182ce` blue) and `.qbank-btn` (`#dd6b20` orange).
   - Add matching glowing drop shadow: `box-shadow: 0 4px 6px rgba(56, 161, 105, 0.2);`.
3. **Controls Container Width**:
   - Expand `.controls-container` `max-width` slightly from `500px` to `560px` to comfortably accommodate all 3 buttons across on desktop viewports.
4. **Mobile Layout & Center Alignment (`@media (max-width: 520px)`)**:
   - Set `.dept-buttons-row` to `flex-wrap: wrap; gap: 0.5rem; justify-content: center;`.
   - Configure `.info-btn-wrapper` on mobile with `flex: 1 1 calc(50% - 0.5rem); max-width: 180px;`, placing **Departmental Info** (`Info`) and **Question Bank** (`Qbank`) side-by-side on the first row.
   - Configure `.club-btn-wrapper` on mobile with `flex: 0 0 100%; max-width: 180px; margin: 0 auto; display: flex; justify-content: center;`, placing **Club Resources** (`Clubs`) on the second row, perfectly **center-aligned**.

### B. JavaScript Controller in [js/departments.js](file:///d:/GitHub/[oU1TS]/b1t-Acad/js/departments.js)
- Immediately beside lines 79–107 (after Departmental Info and Question Bank setup), add **Section 3c: Setup Club Resources Button**:
  ```javascript
  // --- 3c. Setup Club Resources Button ---
  const clubInfoWrapper = document.getElementById('club-info-wrapper');
  if (clubInfoWrapper) {
    const clubLink = deptData.club_res || (typeof clubsData !== 'undefined' && clubsData[dept] ? clubsData[dept].club_drive : '');
    if (clubLink) {
      clubInfoWrapper.innerHTML = `
        <a href="${clubLink}" target="_blank" class="drive-btn club-btn">
          <i class="fa-solid fa-people-group"></i>&nbsp;<span class="btn-text-desktop">Club Resources</span><span class="btn-text-mobile">Clubs</span>
        </a>
      `;
      clubInfoWrapper.style.display = 'flex';
    } else {
      clubInfoWrapper.style.display = 'none';
    }
  }
  ```
- Uses FontAwesome's `fa-people-group` icon (matching the Club Resources section in `index.html`).
- When a department has no `club_res` (empty string `""`), the wrapper remains `display: none`, and the other two buttons retain their clean layout.
